Conclave — Feature List
PROJECT NAME: Conclave
Stack: Java / Spring Boot
Core Differentiator: Multi-Provider Context Unification
Core Concept

A shared "meeting room" where you and multiple LLMs (Claude, GPT, Gemini) discuss in one conversation — no more manually copy-pasting context between tabs

Backend Layer (Spring Boot)

Unified message schema — conversation stored once, in your own normalized format
Per-provider adapter layer — translates the shared format into whatever shape each provider's API actually expects (Claude, OpenAI, Gemini each differ in message/role structure)
Conversation persistence — full shared history stored and reusable across the session
Auth + user accounts

Frontend / Interaction Layer

Chat room UI — different colored bubbles per model, so it's visually clear who said what
@-mention turn-taking — you direct which model responds next (you're the moderator, not an automated one)
Shared context view — every model sees the same conversation history regardless of who's replying

Signature Feature — Multi-Provider Context Unification

The core engineering problem: no two LLM providers expect conversation history in the same shape
Adapter pattern per provider, translating one canonical conversation into three different API formats on demand
Explicitly scoped as integration/systems engineering, not AI engineering — no retrieval, no agentic reasoning in v1, just clean orchestration across providers
